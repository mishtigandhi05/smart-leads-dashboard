# GigFlow – Smart Leads Dashboard

A full-stack MERN application for managing leads with authentication, CRUD operations, filtering, sorting, and pagination.

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS
- Axios
- React Router

Backend:
- Node.js
- Express.js
- TypeScript
- MongoDB Atlas
- JWT Authentication

Deployment:
- Frontend: Vercel
- Backend: Render

---

## Features

- User Login Authentication
- Dashboard UI
- Create Leads
- Update Leads
- Delete Leads
- Search Leads
- Filter by Status & Source
- Pagination
- REST API Integration
- MongoDB Database

### Backend

cd server

## Environment Variables

Create `.env` inside `/server`

PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret_key
